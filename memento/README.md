# Memento - Исходные данные

Эта директория содержит исходные данные, выгруженные из приложения Memento Database. Данные структурированы по библиотекам (папкам) и содержат CSV-файлы с записями и связанные с ними медиафайлы (фотографии).

## Структура

- `gse/`: Данные, относящиеся к пчеловоду "gse".
  - `beekeepers/`: Информация о пчеловодах.
  - `koloda/`: Данные о колодах.
  - `osmotr/`: Записи осмотров.
  - `paseki/`: Информация о пасеках.
  - `test/`: Данные тестов (например, на варроатоз).
- `aay/`, `uin/`: Аналогичные структуры для других пчеловодов.

**Важно:** Эти данные являются "сырыми" и служат источником для обработки и загрузки в базу данных PostgreSQL. Не следует изменять их вручную.
