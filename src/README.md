# `src` - Основная логика приложения

Эта директория содержит основные Python-модули, отвечающие за обработку данных и взаимодействие с базой данных.

## Содержимое

- `data_processor.py`: **Обработчик данных.** Ключевой модуль, который читает "сырые" CSV-файлы из `memento/`, обрабатывает их, вычисляет хэши строк и выполняет операцию `UPSERT` (INSERT или UPDATE) в базу данных.
- `db_manager.py`: **Менеджер базы данных.** Предоставляет функции для управления схемой БД (создание, удаление таблиц) и выполнения `UPSERT` операций.
- `file_utils.py`: **Утилиты для файлов.** Содержит вспомогательные функции для работы с файловой системой, например, для поиска CSV-файлов.
- `serve_static.py`: **HTTP-сервер для статики.** Простой сервер для раздачи изображений из папки `storage/`, что позволяет отображать их в Streamlit-приложении.
- `state_manager.py`: **Менеджер состояния.** Отвечает за отслеживание состояния обработки файлов, используя `storage/processing_state.json`, чтобы избежать повторной обработки уже загруженных данных.
