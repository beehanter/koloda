# `stream` - Streamlit-приложение

Эта директория содержит всё, что относится к веб-приложению для визуализации и анализа данных, построенному на фреймворке Streamlit.

## Содержимое

- `app.py`: **Главный файл приложения.** Точка входа, которая запускает Streamlit и определяет навигацию между страницами.
- `config.toml`: Файл конфигурации Streamlit (в данной реализации не используется, но зарезервирован).
- `map/`: Модуль для отображения данных на карте.
- `table/`: Модуль для отображения данных в виде интерактивных таблиц с использованием гибкого конвейера обработки.
- `utils/`: Вспомогательные утилиты, специфичные для Streamlit-приложения (например, функции для работы с БД).
