# Страница "Карта"

Этот модуль отвечает за отображение страницы с интерактивной картой.

## Структура

-   `map.py`: Главный файл-оркестратор. Он инициализирует и координирует работу всех компонентов пайплайна.
-   `pipeline/`: Директория, содержащая все этапы обработки и отображения данных.
-   `utils/`: Вспомогательные утилиты, например, для работы с PostGIS.
-   `styles.py`: Конфигурационный файл для стилей карты (маркеры, базовые слои, размеры карты).

## Логика работы

1.  **`map.py`** запускает процесс.
2.  **`TableSelector`** (`pipeline/table_selector.py`) отображает в боковой панели чекбоксы для выбора таблиц (`koloda`, `paseki`).
3.  **`PostGISProcessor`** (`utils/geo_utils.py`) загружает данные из выбранных таблиц, извлекая геометрию.
4.  **`FilterStage`** (`pipeline/filter_stage.py`) отображает в боковой панели фильтры по заданным в конфигурации полям и применяет их к загруженным данным.
5.  **`MapConfig`** (`pipeline/map_config.py`) отображает UI для настроек карты, таких как включение и настройка радиуса **буферных зон**.
6.  **`MapRenderer`** (`pipeline/map_renderer.py`) принимает отфильтрованные данные и настройки, после чего отображает их в двух видах:
    *   В виде интерактивных таблиц.
    *   На интерактивной карте `folium` с маркерами и, если включено, с буферными зонами вокруг них.
