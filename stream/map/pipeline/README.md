# Пайплайн страницы "Карта"

Здесь содержатся модули, реализующие отдельные этапы обработки и отображения данных для страницы "Карта".

-   `table_selector.py`: Отображает UI для выбора таблиц в боковой панели.
-   `filter_stage.py`: Отображает UI для фильтрации данных по заданным полям и применяет выбранные фильтры.
-   `map_config.py`: В данный момент не используется активно, но может быть расширен для добавления настроек карты.
-   `map_renderer.py`: Отвечает за финальную отрисовку данных на странице (таблицы и карта `folium`).
