# `stream/utils` - Утилиты для Streamlit

Эта директория содержит вспомогательные модули и функции, которые используются в разных частях Streamlit-приложения.

## Содержимое

- `db.py`: **Утилиты для базы данных.** Содержит функции для подключения к базе данных PostgreSQL и выполнения запросов (`get_db_connection`, `query_to_df`). Этот модуль адаптирован для использования в контексте Streamlit.
