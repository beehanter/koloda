# `stream/table` - Страница с таблицами

Этот модуль отвечает за основную функциональность приложения — отображение данных в виде интерактивной таблицы с гибким конвейером обработки.

## Содержимое

- `table.py`: **Главный скрипт страницы.** Он управляет всем процессом:
    1.  Отображает селектор для выбора таблицы.
    2.  Загружает данные из выбранной таблицы.
    3.  Инициализирует и последовательно применяет все этапы конвейера обработки.
    4.  Отображает итоговый DataFrame.
- `pipeline/`: Директория, содержащая все модули, из которых состоит конвейер обработки данных.
