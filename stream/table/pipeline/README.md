# `stream/table/pipeline` - Конвейер обработки данных

Эта директория содержит модульную архитектуру для последовательной обработки DataFrame в Streamlit-приложении.

## Архитектура

- **`base.py`**: Определяет абстрактный базовый класс `PipelineStage`, от которого наследуются все этапы. Он требует реализации трех методов:
    1.  `render_ui(df)`: Отображает UI-элементы этапа в боковой панели и возвращает `True`, если этап активен.
    2.  `transform(df)`: Применяет преобразование к DataFrame и возвращает измененный DataFrame.
    3.  `show_output(df)`: Отображает дополнительную информацию или результат работы этапа в основной области.

- **Модули этапов**: Каждый файл реализует один конкретный этап обработки:
    - `table_selector.py`: Выбор исходной таблицы.
    - `search_stage.py`: Полнотекстовый поиск.
    - `filter_stage.py`: Фильтрация строк по значениям в столбцах.
    - `group_stage.py`: Группировка данных с агрегацией.
    - `sort_stage.py`: Сортировка данных.
    - `slice_stage.py`: Выбор диапазона строк (`head`/`tail`).
    - `row_selector_stage.py`: Выбор одной конкретной строки для детального анализа.
    - `related_data_stage.py`: Поиск и отображение связанных данных для выбранной строки.

Эта архитектура позволяет легко добавлять, удалять или изменять порядок этапов в основном файле `stream/table/table.py`.
