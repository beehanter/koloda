# `storage` - Хранилище обработанных данных

Эта директория используется для хранения файлов, которые были скопированы и обработаны скриптами из `src/`.

## Содержимое

- `processing_state.json`: **Файл состояния.** JSON-файл, в котором хранится информация о том, какие файлы из `memento/` уже были обработаны. Это позволяет избежать повторной загрузки одних и тех же данных.
- `gse/`, `aay/`, `uin/`: Директории, содержащие копии медиафайлов (фотографий) из `memento/`. Структура папок здесь зеркально отражает структуру в `memento/`. Наличие файлов в этих папках используется для отображения изображений в Streamlit-приложении через статический HTTP-сервер.

**Важно:** Содержимое этой папки генерируется автоматически. Не следует изменять файлы вручную, так как это может нарушить работу `state_manager.py` и `data_processor.py`.
