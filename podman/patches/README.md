# 🔧 SQL Патчи для Koloda

Эта папка содержит SQL патчи для пошагового расширения функциональности БД.

## 📋 Философия патчей

**ПОЧЕМУ НЕ Alembic?**
- SQL патчи проще и прозрачнее
- Нет зависимости от Python библиотек
- Легко откатить вручную
- Идемпотентны (можно применять повторно)
- Версионирование через `schema_version` таблицу
