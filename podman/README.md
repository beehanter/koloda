# Podman - Конфигурация базы данных

Эта директория содержит файлы для настройки и инициализации базы данных PostgreSQL, управляемой через Podman.

## Содержимое

- `Dockerfile`: Инструкции для сборки кастомного образа PostgreSQL, который включает расширения PostGIS и pg_trgm.
- `init.sql`: SQL-скрипт для инициализации базы данных. Он создает все необходимые таблицы (`beekeepers`, `koloda`, `osmotr` и т.д.), определяет их структуру, составные ключи, внешние ключи и индексы. Этот скрипт выполняется автоматически при первом запуске контейнера.

## Использование

Конфигурация управляется через основной файл `Docker-compose.yml` в корне проекта, который использует эти файлы для создания и запуска сервиса базы данных.
