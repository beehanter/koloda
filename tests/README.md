# `tests` - Автоматизированные тесты

Эта директория содержит автоматизированные тесты для проверки корректности работы основной логики приложения. Тесты написаны с использованием фреймворка `pytest`.

## Содержимое

- `test_data_processing.py`: Тесты для модуля `data_processor`, проверяющие логику обработки CSV и формирования данных для БД.
- `test_database.py` / `test_db_manager.py`: Тесты, проверяющие взаимодействие с базой данных, включая операции `UPSERT`.
- `test_file_utils.py`: Тесты для утилит по работе с файлами.
- `test_state_manager.py`: Тесты для менеджера состояния, проверяющие корректность отслеживания обработанных файлов.

## Запуск тестов

Тесты можно запустить из корневой директории проекта с помощью команды:
```bash
pytest
