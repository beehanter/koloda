# Описание проекта

В мобильном приложении Memento я записываю данные о пчёлах. Полученные данные оттуда экспортирую в Яндекс Диск, который синхронизирован с папкой на домашнем ПК, но так же есть и другие пользователи. На настоящий момент есть папка memento, в ней моя папка gse, а в ней 5 подпапок: beekeepers, koloda, osmotr, paseki, test, а так же папки других пользователей aay, uin, с аналогичной структурой. В каждой подпапке находится файл .csv и файлы фото, на которые есть ссылки, записанные в соответствующих полях .csv. При обновлении данных в папке memento, файлы .csv перезаписываются, а файлы фото добавляются.

Мне надо создать приложение, которое будет сохранять данные из csv в базу данных PostgreSQL, а файлы фото копировать в папку storage, имеющей структуру аналогичную папке memento. При запуске надо автоматически проверять папку memento на изменение по времени и хешу. Если в каком то файле csv было изменение, то надо внести данные в соответствующую таблицу Postgres. Изменения могут быть как в виде новых записей, так и изменения в уже существующих, поэтому желательно хеширование строк.

В полях, соответствующих фото, записаны пути к ним в смартфоне. Их надо заменить на пути к ним в папке storage + имя самого файла фото, причём они должны будут срабатывать как ссылки при открытии их в Jupyter Lab или Streamlit.

Есть поля с координатами, их надо преобразовать для PostGis.
Поля с названием data_poroda содержат ссылки на папки в Яндекс Диске и они должны будут так же открываться.

В таблице koloda уникальность записи дает составной ключ из значений полей koloda, region, place, beekeeper. beekeeper так же связан с соответствующим полем в таблице beekeepers.
В таблице osmotr уникальность записи дают значения полей date + koloda, ключом является поле koloda, её значение соответствуют значению составного ключа таблицы koloda.
В таблице test уникальность записи дают значения полей date + koloda, ключом является поле koloda, её значение соответствуют значению составного ключа таблицы koloda.
В таблице paseki уникальность даёт составное значение из полей beekeeper + adres, ключ - поле place, оно соответствует полю place в таблице koloda. Поле beekeeper так же связан с соответствующим полем в таблице beekeepers.

Приложение планируется для ограниченного круга лиц, для использования на локальном ПК без доступа из сети, основное пожелание - простота и надёжность.

Postgres с расширениями pgvector и PostGis устанавливается в Docker контейнере, вместо Docker используется Podman Desktop.
Скрипты на Python с пакетным менеджером uv. Для дальнейшего анализа данных будет использован Jupyter lab.
Для визуализации Streamlit.
