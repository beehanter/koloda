# Документация

Эта директория содержит всю проектную и техническую документацию.

## Содержимое

- `diary.md`: **Дневник разработки.** Хронологический журнал всех ключевых решений, проблем и достижений в ходе работы над проектом.
- `idea.md`: **Идея и требования.** Изначальные цели, требования и общее видение проекта.
- `plan.md`: **План работ.** Детальный план с разбивкой на этапы и задачи.
- `rules_for_kilo.md`: **Правила для ИИ-ассистента.** Внутренний конфигурационный файл с инструкциями для Kilo Code.
