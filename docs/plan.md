# План разработки проекта

Этот документ описывает подробный план работ по созданию приложения для синхронизации данных о пчелах из CSV-файлов в базу данных PostgreSQL.

### Этап 1: Настройка окружения и анализ структуры данных (Завершено)

- [x] **Проверить конфигурацию `uv` и `podman`**: Убедиться, что зависимости устанавливаются, и контейнер с PostgreSQL запускается корректно.
- [x] **Проанализировать структуру CSV-файлов**: Изучить поля, типы данных и связи в файлах `beekeepers.csv`, `koloda.csv`, `osmotr.csv`, `paseki.csv`, `test.csv`.
- [x] **Изучить примеры данных**: Проанализировать реальные данные для понимания форматов координат, путей к фото и ссылок.

### Этап 2: Проектирование и создание схемы базы данных PostgreSQL

- [ ] **Спроектировать схему БД**: Определить таблицы, поля, типы данных, первичные и внешние ключи.
- [ ] **Создать Mermaid-диаграмму**: Визуализировать структуру базы данных и связи между таблицами.
- [ ] **Написать SQL-скрипт (`init.sql`)**: Создать скрипт для автоматического создания таблиц, индексов и включения расширений PostGIS и pgvector.
- [ ] **Протестировать скрипт**: Убедиться, что скрипт выполняется без ошибок и создает корректную структуру в базе данных.

### Этап 3: Разработка модуля для копирования медиафайлов

- [ ] **Реализовать функцию поиска новых файлов**: Написать скрипт, который рекурсивно обходит папку `memento` и находит все медиафайлы (например, `.jpg`).
- [ ] **Реализовать функцию копирования**: Написать логику, которая копирует найденные файлы в соответствующую директорию внутри папки `storage`, сохраняя структуру (`storage/<user>/<library>/...`).
- [ ] **Обеспечить проверку на дубликаты**: Добавить механизм, который предотвращает повторное копирование уже существующих файлов.

### Этап 4: Разработка модуля для обработки и загрузки CSV-данных в PostgreSQL

- [ ] **Создать скрипты для чтения CSV**: Написать функции для чтения каждого из 5 типов CSV-файлов с помощью библиотеки `pandas` или `csv`.
- [ ] **Разработать функции преобразования данных**:
    - Преобразование координат в формат PostGIS `POINT`.
    - Генерация новых путей к фото в папке `storage`.
    - Парсинг составных ключей (например, поля `koloda` в `osmotr.csv`).
    - Преобразование дат в формат `timestamp`.
- [ ] **Реализовать логику `UPSERT`**: Написать функции для добавления (INSERT) и обновления (UPDATE) записей в PostgreSQL. Использовать `row_hash` для определения измененных строк.
- [ ] **Организовать транзакции**: Обернуть операции с базой данных в транзакции для обеспечения целостности данных.

### Этап 5: Реализация логики отслеживания изменений в файлах

- [ ] **Разработать механизм кеширования состояния файлов**: Создать систему (например, JSON-файл или отдельную таблицу в БД) для хранения метаданных о файлах: путь, время последней модификации, хеш-сумма.
- [ ] **Написать функцию проверки изменений**: Реализовать логику, которая при запуске сравнивает текущее состояние файлов в `memento` с сохраненным в кеше.
- [ ] **Определять измененные файлы**: Если время модификации или хеш файла изменились, пометить его для обработки.

### Этап 6: Интеграция всех модулей в единое приложение

- [ ] **Создать главный управляющий скрипт (`main.py`)**: Этот скрипт будет оркестрировать весь процесс.
- [ ] **Определить последовательность вызовов**:
    1. Проверка изменений в файлах (`Этап 5`).
    2. Копирование новых медиафайлов (`Этап 3`).
    3. Обработка и загрузка данных из измененных CSV (`Этап 4`).
- [ ] **Добавить конфигурационный файл (`.env`)**: Вынести настройки (пути, доступы к БД) в переменные окружения.
- [ ] **Реализовать логирование**: Настроить логирование для отслеживания процесса выполнения, ошибок и предупреждений.

### Этап 7: Создание Jupyter Notebook для проверки и анализа данных

- [ ] **Настроить подключение к БД в Jupyter**: Установить необходимые библиотеки (`psycopg2-binary`, `sqlalchemy`, `geopandas`).
- [ ] **Написать запросы для выборки данных**: Создать примеры SQL-запросов для получения данных из всех таблиц.
- [ ] **Визуализировать данные**:
    - Построить карты с использованием `geopandas` для отображения координат.
    - Создать интерактивные ссылки на локальные фото и внешние ресурсы (Яндекс.Диск).
- [ ] **Подготовить примеры анализа**: Продемонстрировать базовые возможности анализа данных, хранящихся в БД.
