# Jupyter Notebooks

Эта директория содержит Jupyter Notebooks для исследовательского анализа данных, прототипирования и визуализации.

## Содержимое

- `1.ipynb`, `data_analysis.py`: Примеры ноутбуков для анализа данных из базы, построения карт с координатами и других исследовательских задач.

Ноутбуки в этой папке не являются частью основного приложения и используются исключительно для вспомогательных и аналитических целей.
