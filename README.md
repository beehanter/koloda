# Проект "Koloda" - Анализ данных о пчеловодстве

Этот проект представляет собой комплексное приложение для сбора, хранения и анализа данных, экспортируемых из мобильного приложения Memento.

## Основные возможности

- **Автоматическая синхронизация**: Приложение отслеживает изменения в CSV-файлах и автоматически загружает их в базу данных PostgreSQL.
- **Хранение медиафайлов**: Связанные с записями фотографии копируются в локальное хранилище.
- **Аналитический интерфейс**: Веб-приложение на Streamlit предоставляет инструменты для просмотра, фильтрации и визуализации данных.

## 🚀 Инструкция по установке и запуску для тестирования

Этот раздел предназначен для пользователей, которые не знакомы с программированием.

### Шаг 1: Установка необходимого ПО

Первое, что нужно установить — это **Podman Desktop**.
1.  Перейдите на официальный сайт: [podman-desktop.io](https://podman-desktop.io/)
2.  Скачайте установщик для вашей операционной системы (Windows или macOS).
3.  Запустите установщик и следуйте инструкциям на экране.
Второе, что нужно установить — это **Visual Studio Code**.
1.  Перейдите на официальный сайт: [Download Visual Studio Code](https://code.visualstudio.com/Download)
2.  Скачайте установщик для вашей операционной системы (Windows или macOS).
3.  Запустите установщик и следуйте инструкциям на экране.

### Шаг 2: Получение файлов проекта

Вам не нужно использовать Git или сложные команды. Просто скачайте все файлы проекта одним архивом.
1.  Сохраните ZIP-архив на свой компьютер ([ZIP-архив](https://github.com/beehanter/koloda/archive/refs/heads/home.zip)).
2. Распакуйте его в удобное для вас место.

### Шаг 3: Запуск приложения (в 2 этапа)

1.  **Запустите VS Code** перейдите в папку с проектом, в которую вы распаковали.
2.  **Откройте терминал** Выполните команду "uv sync". Дождитесь пока загрузятся все зависимости.
Выполните команду ".venv\scripts\activate".
Выполните команду ".\podman\build.bat". Дождитесь пока пройдёт сборка всех образов.
Выполните команду "podman compose up -d". Об окончании процесса можно судить по появлению файла "processing_state.json" в папке "storage".
Дождитесь, пока в терминале не появится надпись "Build complete."
3.  **Проверка.** Откройте ваш веб-браузер (Chrome, Firefox и т.д.) и перейдите по адресу: [http://localhost:8501](http://localhost:8501). Вы должны увидеть интерфейс приложения.

### Шаг 4: Остановка приложения

1.  Вернитесь в терминал.
2.  Выполните команду, чтобы полностью остановить и удалить контейнеры:
    "podman-compose down"
3.  Теперь приложение полностью остановлено.
