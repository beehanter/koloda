# Проект "Koloda" - Анализ данных о пчеловодстве

Этот проект представляет собой комплексное приложение для сбора, хранения и анализа данных, экспортируемых из мобильного приложения Memento.

## Основные возможности

- **Автоматическая синхронизация**: Приложение отслеживает изменения в CSV-файлах в папке `memento` и автоматически загружает обновленные данные в базу данных PostgreSQL.
- **Хранение медиафайлов**: Связанные с записями фотографии копируются в локальное хранилище `storage`.
- **Аналитический интерфейс**: Веб-приложение на Streamlit предоставляет инструменты для просмотра, фильтрации и визуализации данных на интерактивной карте.

## Быстрый запуск (для Windows)

Для удобства развертывания и управления всеми компонентами приложения были созданы два скрипта.

### 1. Запуск всех сервисов

Чтобы запустить базу данных, все фоновые скрипты и веб-интерфейс, выполните в терминале PowerShell:

```powershell
.\start.bat
```

Эта команда запустит:
- Базу данных PostgreSQL в Podman.
- Скрипт `main.py` для обработки данных.
- Сервер `serve_static.py` для раздачи изображений.
- Приложение Streamlit.

### 2. Остановка всех сервисов

Для корректного завершения работы всех запущенных процессов выполните:

```powershell
.\stop.bat
```

Эта команда остановит все контейнеры и завершит все связанные процессы.
